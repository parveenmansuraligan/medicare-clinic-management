# MediCare Clinic Management System

A small healthcare clinic management demo created for software testing practice.

## Modules
- Admin Login
- Dashboard
- Patient Management
- Doctor Management
- Appointment Management
- Visits & Prescriptions

## Demo Login
Username: admin
Password: admin123

## Main workflows
Patient registration, patient search/edit/delete, doctor records, appointment booking and conflict validation, visit notes, diagnosis and prescriptions.

## Notes
This is a demo application. Data is stored in the browser's localStorage and is intended for testing/learning purposes only. Do not enter real patient/medical information.
